# :school_satchel: Modern Dark & Emerald ox_inventory Reskin

A sleek, modern dark-themed reskin for **[ox_inventory](https://github.com/overextended/ox_inventory)**. Designed with rounded geometry, smooth contrast, and high-visibility emerald accents for an immersive, clean FiveM roleplay experience.

---

## :sparkles: Features

- **Modern Dark UI:** Deep obsidian backdrops with subtle translucent borders and rounded corners.
- **Emerald Accent Styling:** Bright green highlights for active states, primary actions, and weight bars.
- **Integrated Clothing / Accessories Tab:** Clean toggle panel for hats, glasses, masks, tops, pants, shoes, and jewelry[cite: 2].
- **Refined Action Controls:** Redesigned middle stack with dedicated quick action buttons (`Use`, `Give`, `Close`).
- **Clean Tooltip & Control Helper Modal:** Clear shortcut cheat-sheet for player accessibility[cite: 3].
- **Optimized & Lightweight:** Zero impact on resmon / UI performance.

##  Default Keybinds & Shortcuts

| Action | Combination |
| :--- | :--- |
| **Context Menu** | `RMB`[cite: 3] |
| **Fast Use Item** | `ALT` + `LMB`[cite: 3] |
| **Fast Move Stack** | `CTRL` + `LMB`[cite: 3] |
| **Split Half Stack** | `SHIFT` + Drag[cite: 3] |
| **Fast Move Half Stack** | `CTRL` + `SHIFT` + `LMB`[cite: 3] |
